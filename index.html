多模态仇恨言论检测模型的图像标注

CS5495 Explainable AI 课程项目 · 内部标注页 不公开索引

这个项目在做什么

被审计的模型是 Amirhossein75/clip-vit-base-mmhs150k-mtl：CLIP 的图像塔与文本塔， 加一个门控融合和五个类别头，输入是「推文文字 + 配图」。模型的准确率已经验证过与作者公布的一致， 所以问题不是「它准不准」，而是它到底有没有用图。

现有结论是文字主导：模态 Shapley 分解里文字平均贡献 +0.047，图像只有 +0.0014， 文本主导 99.4% 的样本。这个结论要成立，必须先排除三种解释方式上的伪影， 而这三件事都只能靠人眼判断，机器判不了。

需要标注什么

页面数量判断什么用来做什么
gold.html200 图里有没有可读的文字 OCR 金标准：算出 EasyOCR 的检出率与误检率，说明分组误差的方向
concept.html1924 图里有没有可读的文字 概念集 QC：末尾 100 张是盲复标，用来算标注一致率（门槛 0.8）
membership.html600 这张图是否属于页面上写的那个概念 概念归属抽检：概念集是检测器自动生成的，这一步测它的敏感度与特异度

三个页面合计 2724 次判断。全部做完约 70–100 分钟；只做 gold 与 membership（800 次） 约 25 分钟，也够支撑报告里需要人工数据的两处结论。

怎么标

  1. 先点开一个页面，在右上角填标注者代号，导出的文件名会带这个名字。
  2. 键盘 1 / 2 / 3 选择，← 回退到上一张，选完自动跳下一张。
  3. 进度存在浏览器本地，关掉页面再打开会从第一张没标的继续。
  4. 标完点「导出结果」，把下载的 JSON 发回给项目组，放进 annotate/out/ 后由脚本合并。
两点要求。一是按第一眼判断，不要放大反复找；二是不要顺着某一类图的规律去猜， 页面故意不显示检测结果和样本来源，就是为了让判断独立。

关于数据

图片来自公开数据集 MMHS150K，内容是真实的推文配图，包含仇恨言论与冒犯性画面。 标注结果只用于这次课程作业的统计分析，不用于训练模型，不对外发布，不进入任何公开数据集。

这个站点是公开可访问的 GitHub Pages，没有登录。链接不要转发到公开渠道； 页面加了 noindex，不会被搜索引擎收录，但拿到链接的人都能打开。
